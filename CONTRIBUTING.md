# Contributing

This repository is a personal profile README, so it does not take feature contributions. Corrections are welcome: a broken link, a typo or a stale project description. Open an issue, or a pull request with the fix.

`README.md` is partly generated by `scripts/update_readme.py` (the "latest releases" block). Edit the script rather than the generated block, and run `python3 scripts/update_readme.py` to check the result before you open the pull request.

For contributions to any other repository, read that repository's `CONTRIBUTING.md`; the account-wide [contributing guide](https://github.com/basitalisandhu/.github/blob/main/CONTRIBUTING.md) applies where a repository has none.
