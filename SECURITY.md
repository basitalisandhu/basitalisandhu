# Security policy

This repository is a profile README and the script that refreshes it. It holds no application code, secrets or user data.

To report a vulnerability in any repository under [github.com/basitalisandhu](https://github.com/basitalisandhu), including this one, use GitHub's private vulnerability reporting on the affected repository (**Security** tab, **Report a vulnerability**). The full policy, with what to include and the response times, is the account-wide [security policy](https://github.com/basitalisandhu/.github/blob/main/SECURITY.md).
